# 🛡️ Intrusion Detection System (IDS)

A Machine Learning-based **Intrusion Detection System (IDS)** developed using **Python, Scikit-learn, Pandas, and Flask** to detect malicious network traffic in real time. The system analyzes network data, classifies suspicious activities, and helps enhance cybersecurity by identifying potential attacks with high accuracy.

---

## 📌 Overview

The Intrusion Detection System (IDS) is designed to monitor network traffic and identify malicious activities using supervised machine learning algorithms. It classifies incoming traffic as **Normal** or **Attack**, providing an additional layer of security against cyber threats.

The application features a user-friendly web interface where users can input network traffic data and receive instant predictions. It also includes secure user authentication to ensure controlled access.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Intrusion-Detection-System.git
```

Navigate to the project folder

```bash
cd Intrusion-Detection-System
```

Install the required dependencies

```bash
pip install -r requirements.txt
```

Run the Flask application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```
